# Project brief

## Purpose

DSGroup is a Ukrainian ecommerce storefront for electronics and blackout-resilience goods. It is intentionally sized for a curated catalogue of up to roughly 100 products, with a fast customer experience and a practical Django Admin workflow.

## Repository map

- `dsgroup-store-backend`: Django API, data, admin, order processing.
- `dsgroup-store-frontend`: Next.js customer storefront and SEO surface.
- `dsgroup-store-infrastructure`: repeatable local startup, launch agents and this shared operational memory bank.

## Non-goals until a provider is selected

Online payments, delivery-carrier integration, transactional email/SMS, production hosting, and analytics consent tooling.
